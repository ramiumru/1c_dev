# Пример дополнительного агента (example overlay)

> Dummy-файл из examples/overlay/. Реальный agent-override живёт в private overlay.

Категория `agents/` копируется в `<agentDir>/`. Файл, совпадающий по имени с
public-агентом (например `agents/1c-developer.md`), заменяет установленную копию
(override); новый файл (например этот) — добавляется (add).
