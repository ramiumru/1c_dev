# Выбор агента в OpenWork

Шаблон `adapters/openworks/opencode.json.tpl` не задаёт `default_agent`.
Harness устанавливает агентов и контекст, но не выбирает стартового агента за
пользователя. Не прописывается и принудительный `build`: сохраняются глобальные
настройки и явный выбор пользователя. При стандартных настройках OpenCode
универсальный первичный агент — Build (`build`). Для агентской схемы 1С пользователь
выбирает `1c-do`; он остаётся primary-агентом, остальные режимы ролей не меняются.

OpenCode определяет `default_agent` как выбор, когда агент не указан явно,
а не запрет переключения. OpenWork использует OpenCode, но доступность переключателя
зависит от версии интерфейса. В OpenWork issue #2101 описано отсутствие picker
в версиях 0.15.1/0.15.2; issue закрыт через #2155. Это подтверждает существование
такого ограничения в тех версиях, но не доказывает универсальную блокировку
при любом `default_agent` или наличие того же бага в текущей версии пользователя.

## Уже установленный проект

Установщик формирует `opencode.json`, а OpenCode также поддерживает `opencode.jsonc`.
Существующий пользовательский config не перезаписывается обычным install/update.
Ваш `"default_agent": "build"`, `"plan"` или custom agent сохраняется.
Если старый файл всё ещё содержит навязанный `"default_agent": "1c-do"`, обычный
update не удаляет его молча: уберите только этот ключ в фактически используемом
конфиге либо выберите желаемое значение самостоятельно. Не используйте общий Force
для смены одного параметра. Сохранённый на стороне приложения выбор существующего
чата может потребовать отдельного переключения или нового чата.

Изменение шаблона не гарантирует появления picker в OpenWork. Уточните версию
приложения, если custom primary-агенты по-прежнему недоступны. @mention может
делегировать субагенту и не эквивалентен переключению основного агента.

## Проверки

`validate.py` проверяет отсутствие default_agent в исходном шаблоне и после
реальной установки, идемпотентную переустановку и сохранение пользовательского
JSON/JSONC выбора при install/update (build, plan, custom). При явном Force
проверяется backup и точное соответствие новому шаблону без default_agent.
Права, модели и тела агентов, а также default Kilo эта правка не меняет.
