# Строки, шаблоны и локализация BSL

Применять при создании и изменении строк, включая artifact-only. Проверять изменяемый
код; массовая переделка соседнего кода вне scope не требуется.

- Составные строки с подстановками оформлять через `СтрШаблон`, если шаблон делает
  выражение понятнее: вместо `Имя + " (" + Код + ")"` — `СтрШаблон("%1 (%2)", Имя, Код)`.
  Проверять соответствие `%1`…`%10` аргументам; для литерального процента — `%%`.
- Пользовательские сообщения, предупреждения, заголовки, подписи, подсказки и ошибки,
  показываемые пользователю, задавать через `НСтр`. По умолчанию новый текст на одном
  языке: `НСтр("ru = 'Документ сохранён.'")`. Другие языки добавлять по требованиям
  проекта; существующие переводы сохранять. Не фиксировать второй аргумент `НСтр`
  в `"ru"`: язык выбирается средствами платформы.
- Для составного пользовательского текста использовать **одну целую фразу** в `НСтр`
  и подстановку через `СтрШаблон`; не склеивать локализованные слова, пробелы и значения.
  Варианты фразы с разным смыслом — отдельные полные шаблоны.

```bsl
ТекстСообщения = СтрШаблон(
    НСтр("ru = 'Документ %1 от %2 сохранён.'"),
    НомерДокумента, Формат(ДатаДокумента, "ДЛФ=D"));
```

- Региональное представление дат и чисел получать через `Формат` по смыслу задачи.
  Не навязывать `Л=ru_RU` и не менять настройки сеанса/конфигурации ради русской фразы.
  Нестандартные форматные строки с языковыми словами также требуют локализации.
- Технические имена метаданных, ключи JSON/XML, пути, URL, текст алгоритмов и запросов
  не оборачивать в `НСтр`. Тексты для пользователя из запроса передавать параметрами.
- Не заменять `+` механически: простое присоединение технического суффикса, разделителя,
  переносов строк или лога допустимо, когда понятнее шаблона. Для накопления большого
  текста в цикле рассмотреть массив фрагментов и `СтрСоединить`, а не цепочку шаблонов.
  Выбор объяснять при нетривиальном исключении; проверять используемый API по проекту.
- «Языковой блок» здесь — литерал `ru = '…'` внутри `НСтр`; отдельная `#Область` для
  каждой строки не нужна. Соблюдать существующую структуру областей модуля.
