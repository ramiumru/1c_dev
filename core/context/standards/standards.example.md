# Стандарты разработки (шаблон)

> Этот файл — шаблон. Замените его содержимым стандартов вашей компании.
> Корпоративные стандарты хранятся в `overlay/standards/` и не входят в публичную поставку.

## Именование

- новые реквизиты/ТЧ в типовых объектах — с префиксом проекта (из `.dev.env`, поле `PREFIX`);
- новые объекты конфигурации — с префиксом проекта; подчинённые элементы — без префикса;
- префикс проекта — из `.dev.env` (поле `PREFIX`).

## Комментарии изменений

`// ++ #<TASK-ID>` … `// -- #<TASK-ID>` (TASK-ID из SDD-процесса). Без фамилий, дат, emoji.

## Запросы

- оформление как в конструкторе;
- комментарии вне текста запроса.

## БСП-функции

Использовать вместо самописных (перечень — в стандартах платформы 1С).

## Формы

Типовые формы — только программно; рекомендуемо `<префикс>ДобавитьЭлементыФормы()` в конце `ПриСозданииНаСервере`.
