# Справочный индекс часто используемых объектов

Этот файл — справочный индекс часто используемых объектов. Объекты ниже относятся к
проекту **`finance`** (БИТ.ФИНАНС / БИТ:Строительство КОРП 3.0); для иных проектов
аналогичный список формируется по мере появления ключевых объектов (объекты помечаются
проектом через поле `Проект:` в `.kilo/context/projects/<проект>/objects-index.md`).
Индекс **не ограничивает** анализ: аналитик `1c-analyst` работает со всей конфигурацией
проекта из Task-брифа. Назначение — ускорить поиск и дать быстрые ссылки.

> **Проект:** `finance`. Пути — в `.kilo/context/projects/<проект>/objects-index.md`, поле `Путь:` каждого объекта
> (квалифицированы как `projects/finance/src/...`). Summaries — в
> `.kilo/context/projects/finance/summaries/`. Для другого проекта путь заменяется на
> `projects/<проект>/src/...`, summaries — на `.kilo/context/projects/<проект>/summaries/`.

## Синхронизация

Файл — справочный индекс часто используемых объектов, не ограничение.

- Аналитик `1c-analyst` имеет полный доступ к `projects/<проект>/src/**` и право редактировать
  этот файл, `.kilo/context/projects/<проект>/objects-index.md`, `.kilo/context/projects/<проект>/summaries/**` и `.kilo/context/projects/<проект>/context.md`.
- При добавлении или удалении объекта обновлять этот файл (список объектов) и
  `.kilo/context/projects/<проект>/objects-index.md` (блок объекта: `Проект:` / `Путь:` / `Назначение:` /
  `Что смотреть:` / `Связанные`). Путь указывать с префиксом `projects/<проект>/src/`.
- Краткие описания объектов писать в `.kilo/context/projects/<проект>/summaries/` по маппингу ниже.
- Скрипт `scripts/build_summaries.py` — регенератор summaries (per-project; проект выводится
  из пути объекта). Запускается субагентом `1c-tools` через `1c-do` (явный запрос,
  авто-обновление post-SDD, либо авто-обнаружение новых объектов через `--scan`), либо
  пользователем вручную вне сессии. Аналитик может править summaries вручную; сам скрипт не
  запускает (`bash: deny`).

## Маппинг summary-файлов

Summaries лежат per-project: `.kilo/context/projects/<проект>/summaries/<filename>.md`. Маппинг имён (для проекта
`finance`):

- `Справочник.X` → `.kilo/context/projects/finance/summaries/Catalog.X.md`
- `Документ.X` → `.kilo/context/projects/finance/summaries/Document.X.md`
- `Перечисление.X` → `.kilo/context/projects/finance/summaries/Enum.X.md`
- `ОбщийМодуль.X` → `.kilo/context/projects/finance/summaries/CommonModule.X.md`
