# Документ.лвл_АктВыполненныхРабот

Проект:
`finance`

Путь:
`projects/finance/src/Documents/лвл_АктВыполненныхРабот/`

Назначение:
Акт выполненных работ — фиксирует фактически выполненные объёмы
работ на объекте учёта по данным ведомости.

Что смотреть:
- `Ext/ObjectModule.bsl` — обработчики проведения (`ОбработкаПроведения` → `ОбработкаПроведенияНоваяСмета`), `ПриЗаписи`, работа с `ЗачетАвансов`
- `Ext/ManagerModule.bsl` — `РассчитатьЗависимыеРеквизиты` (формула «ИтогоКОплате = СуммаВсегоСКомпенсацией − (… + ЗачетАвансов.СуммаЗачета + ЗачетАвансов.СуммаРаспред + …)»)
- `Forms/ФормаДокумента/` — основная форма (вкладка КС-3, кнопка `РассчитатьКС3`; процедуры `РассчитатьКС3НаСервере`, `ПодобратьАвансы` [хитрая формула СМР], `ТаблицаДокументовРасчетовСКонтрагентом`, `УстановитьВидимостьДоступностьКС3`, `ЭтоДоговорСМР(ДоговорКонтрагента)` [локальная, `&НаСервереБезКонтекста`, через `бит_стр_ЭтоСтроительство` + `lvv_ВидДоговора`], `РассчитатьКОплате`)
- `Forms/ФормаДокументаДерево/` — форма-дерево (симметричная логика; ветвление СМР/не-СМР в `УстановитьВидимостьДоступностьКС3` уже реализовано через локальную `ЭтоДоговорСМР(Объект.ДоговорКонтрагента)`; заголовок кнопки: «Рассчитать по типовой формуле» [СМР] / «Подобрать авансы» [не-СМР]. **Внимание:** `РассчитатьКС3НаСервере` пока НЕ разветвлена — хитрая формула вызывается для всех договоров; задача TASK-123125601 — добавить ветвление для не-СМР)
- `Forms/ПодборДокументов/` — форма ручного подбора авансов (синоним «Подбор документов»; пользователь называет «Расчеты») по остаткам Дт 60.02 (`РегистрБухгалтерии.Хозрасчетный.Остатки` на `КонецДня(дата акта)`)
- `Forms/ФормаСписка/` — форма списка
- XML объекта: реквизиты (`ДоговорОснование`, `ДоговорКонтрагента`, `ИтогоКОплате`, `Удержание`, `СпособЗачетаАвансов`, `Статус`), ТЧ (`ЗачетАвансов` [ДокументАванса, СуммаЗачета, СуммаРаспред, Распред, Номинация], `Работы` [СуммаСМР], `РаботыМатериалы`, `РасчетКомпенсации`, `УдержанияПоПретензиям`, `ШтрафыКОплате`, `ПоставленныеМатериалы`, `УчтенныеКоммунальныеРасходы`, `ТекущееОбеспечениеСтроительства`). **Примечание:** XML-файл объекта `лвл_АктВыполненныхРабот.xml` отсутствует в выгрузке — структура подтверждена по BSL-коду.

Связанные объекты:
- `Справочник.лвл_Работы`
- `Справочник.лвл_ОбъектыУчета`
- `Документ.лвл_ВедомостьОбъемовРабот`
- `Документ.лвл_Смета`
- `Документ.лвл_УсловияДоговора` (договор-основание через `ДоговорОснование`; менеджерская `ВидДоговораСМР(...)` существует, но **в формах акта НЕ используется** — применяется локальная `ЭтоДоговорСМР(Объект.ДоговорКонтрагента)` через реквизиты справочника-договора `бит_стр_ЭтоСтроительство` + `lvv_ВидДоговора` [префикс `lvv_` — латиница])
- `Перечисление.лвл_ТиповаяФорма` (Сложная/Простая/НеТиповая — «типовая форма», используется в метрике «обязательная кнопка», НЕ признак СМР)
- `Перечисление.лвл_СтатусыАктовВыполненныхРабот` (`СогласованВДО`, `Подписан` — участвуют в видимости групп КС-3 для СМР)
- `Справочник.lvv_ВидыДоговоров` (предопределённое `СМР`; префикс `lvv_` — латиница, нестандартный для проекта)
- `РегистрНакопления.лвл_уус_ВыполнениеДоговоров` (остаток работ по договору для хитрой формулы `ОстатокРаботПоДоговору()`, только СМР)
- `РегистрБухгалтерии.Хозрасчетный` (счёт 60.02 — источник остатков авансов через БСП `ДокументРасчетовСКонтрагентом.ПолучитьДанныеСпискаВыбораПоОстаткам`; зачёт при проведении — стандартный БСП `СпособЗачетаАвансов = ПоДокументу`)
