# Контекст проекта: `finance`

Проект-специфичный контекст для конфигурации, лежащей в `projects/finance/src/**`.
Общий (схемный) контекст — в `INSTRUCTIONS.md`. Этот файл читают агенты по полю
«Проект» из Task-брифа (определяет `1c-do`, см. шаг 1.5 алгоритма `1c-do`).

## Платформа и конфигурация

- Платформа: **1С:Предприятие 8.3.27**, управляемые формы
- Язык: **BSL**
- Конфигурация (Name из метаданных): **`БухгалтерияПредприятияКОРП`**
- Vendor: `БИТ`
- Архитектура слоёв (составная конфигурация):
  - **База:** Бухгалтерия Предприятия 3 КОРП (типовая 1С) — все документы и процессы бухгалтерии.
  - **Слой 1:** модуль **БИТ.ФИНАНС** (управленческий учёт).
  - **Слой 2:** модуль **БИТ: Строительство** (отраслевая доработка).
  - Маркетинговое имя сборки: «БИТ: Строительство (БИТ.ФИНАНС) КОРП, редакция 3.0».
- Нумерация релиза: `3.0.194.23/3.1.66.8/3.0.1.294`
  - `3.0.194.23` — релиз Бухгалтерия Предприятия 3 КОРП;
  - `3.1.66.8` — релиз модуля БИТ.ФИНАНС;
  - `3.0.1.294` — релиз модуля БИТ: Строительство.

## Источники

- `finance` — основная конфигурация (БухгалтерияПредприятияКОРП)
- `extfinance` — расширение (запланировано)

## Бизнес-домен

Управление сметами, тендерами и закупками в строительном контексте:

- Виды документов сметы: Оферта, Расчётная стоимость, Коммерческое предложение, Предварительное КП
- Структура: работы → материалы (ТЧ + расшифровка), объекты учёта
- Интеграция с тендерами, номинациями материалов, НСИ
- Банковские обмены (XDTO-пакеты): зарплатные проекты (`ФорматОбменаСБанкамиПоЗарплатнымПроектам`),
  выплаты самозанятым (`ФорматОбменаСБанкамиПоВыплатамСамозанятым`)

## Часто используемые модули

| Модуль | Назначение |
|---|---|
| `лвл_ОбщегоНазначенияСервер` | Утилиты серверной стороны |

| `лвл_РаботаСНСИСервер` | Работа с НСИ (нормативно-справочная информация) |

Важно: перечисление модулей — справочное. Аналитик `1c-analyst` имеет полный доступ к
`projects/finance/src/CommonModules/**` и читает модули точечно по необходимости
(алгоритм шагов 3-5), а не все подряд.

## Ключевые объекты конфигурации

### Справочный индекс объектов УУС

Актуальный справочный список объектов УУС (контур `finance`) —
`.kilo/context/projects/finance/analyst-scope.md` (объекты помечены проектом через поле `Проект:`
в `.kilo/context/projects/finance/objects-index.md`). Аналитик `1c-analyst` работает со всей конфигурацией
`projects/finance/src/**`; индекс УУС не ограничивает анализ, а ускоряет поиск.

### Прочие ключевые объекты (не входят в справочный индекс УУС)

| Объект | Назначение |
|---|---|
| `Документ.лвл_Тендер` | Тендер, хранит лоты и оферты |
| `Перечисление.лвл_ВидыОперацийСмета` | Виды операций документа Смета |
| `Перечисление.лвл_уус_ВерсииДанных` | Версии данных (Версия2, История) |

Эти объекты доступны для анализа (исходники присутствуют в `projects/finance/src/**`);
они просто не включены в справочный индекс УУС и не имеют summary-файлов.
