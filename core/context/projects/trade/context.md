# Контекст проекта: `trade`

Проект-специфичный контекст для конфигурации, лежащей в `projects/trade/src/**`.
Общий (схемный) контекст — в `INSTRUCTIONS.md`. Этот файл читают агенты по полю
«Проект» из Task-брифа (определяет `1c-do`, см. шаг 1.5 алгоритма `1c-do`).

## Платформа и конфигурация

- Платформа: **1С:Предприятие 8.3.27**
- **Обычные формы** — конфигурация обычного приложения
  (`UseManagedFormInOrdinaryApplication=true`, `UseOrdinaryFormInManagedApplication=false`).
  Формы — обычные (не управляемые), модули — на архитектуре обычного приложения.
- Язык: **BSL**
- Конфигурация (Name из метаданных): **`УправлениеТорговлей`**
- Vendor: `Фирма "1С"` (типовая 1С)
- Version: `10.3.13.2`
- База: типовая **1С:Управление торговлей 10.3** (УТ 10.3) на архитектуре обычного приложения,
  доработанная сторонними модулями и интеграциями.

## Источники

- `trade` — основная конфигурация (УправлениеТорговлей)

## Бизнес-домен

Универсальная торговля (ядро УТ 10.3) + множество интеграций и отраслевых доработок:

- **Торговое ядро УТ 10.3:** закупки, продажи, склад, розница, взаиморасчёты, НДС, платежи
  (типовые объекты без префикса: `ЗаказПокупателя`, `РеализацияТоваровУслуг`,
  `ПоступлениеТоваровУслуг`, `ЧекККМ`, `СчетФактураВыданный`, регистры `Продажи`,
  `ТоварыНаСкладах`, `ВзаиморасчетыСКонтрагентами`, `НДС*`).
- **CRM** (`CRM_*`, подсистема `CRM`): маркетинг, обращения, значимые события, интеграция с телефонией.
- **Автосервис БИТ** (`бит_ус_*`, подсистема `бит_ус_Сервис`): заказ-наряды, исполнители,
  нормо-часы, работы, запчасти.
- **Авторазбор/запчасти** (`Артем_*`, `артем_*`): агрегаты, аналоги, цепи исполнителей.
- **Авито-интеграция** (`ns*`, подсистема `nsАвито`): выгрузка объявлений, магазины, категории.
- **СПАРК Риски** (`w*`, подсистема `WizardСПАРКРиски`): мониторинг контрагентов.
- **Телефония/СМС** (`МИКО_*`, `смс*`, `CTI_*`): звонки, запись переговоров, SMS-рассылки.
- **ЭДО/банк-клиент** (XDTO: `ClientBankExchange`, `УведомлениеОбУточненииЭД`,
  `ТранспортнаяИнформацияТакском`; ExchangePlans: `Полный`).
- **Обмен с сайтом/Битрикс** (`ОбменССайтом`, `Битрикс`, `бф*`); Google интеграция
  (`CRM_GoogleИнтеграция`).

## Префиксы в данном проекте

| Префикс | Что обозначает |
|---|---|
| `CRM_` | Модуль CRM |
| `бит_`, `бит_ус_` | Библиотека БИТ (Управление сервисом / автосервис) |
| `Артем_`, `артем_` | Доработки (авторазбор) |
| `ns` | Интеграция с Авито |
| `w` | СПАРК Риски (Wizard) |
| `МИКО_`, `смс` | Телефония МИКО / СМС |
| `бф` | Битрикс/бухфон |
| `КК_` | Кастомный модуль (уточнить по необходимости) |
| без префикса | Типовые объекты УТ 10.3 / БСП |

## Часто используемые модули

`projects/trade/src/CommonModules/**` и читает модули точечно по необходимости, а не все подряд.

| Модуль (префикс/группа) | Назначение |

| `МИКО_*` | Телефония МИКО |
| `смс*` | СМС-рассылки |
| `ns*` | Интеграция с Авито |

## Summaries

Summaries проекта `trade` лежат в `.kilo/context/projects/trade/summaries/`
(per-project, кэш — `.kilo/context/projects/trade/summaries/.cache.json`).
Каталог пока не существует — регенерация через `scripts/build_summaries.py`
(режим `--scan --objects` для добавления объектов в индекс и построения summaries).
Проект выводится из пути объекта автоматически.
