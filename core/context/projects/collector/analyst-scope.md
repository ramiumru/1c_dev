# Analyst Scope: `collector`

Справочный список часто используемых объектов проекта `collector` (ускоритель поиска, не ограничение анализа).
Полный индекс путей/связей — в `objects-index.md`. Summaries — в `summaries/` (после регенерации через `1c-tools`).

## Ключевые объекты по доменам

### Lego (минифигуры / наборы)
- `Справочник.КлассификаторМинифигурокLego` — `Catalogs\КлассификаторМинифигурокLego\` (карточки минифигурок; реквизиты: Серия, ТипФигурки, ТипВыпуска, ДатаВыпуска, Масса, Габариты, КоличествоДеталей, ВСколькоНаборовВходит).
- `Справочник.НаборыLego` — `Catalogs\НаборыLego\`.
- `Справочник.СостоянияНаборовLego` — `Catalogs\СостоянияНаборовLego\`.
- `Обработка.ПарсингСайтаBricksapp` — `DataProcessors\ПарсингСайтаBricksapp\` (целевой парсер bricksapp.ru; клиентский DOM через `Поле HTML-документа`).
- `Обработка.ПарсингСайтаBricklink` — `DataProcessors\ПарсингСайтаBricklink\` (старый, нерабочий; образец копирования).
- `Документ.РазборНаборовLego` — `Documents\РазборНаборовLego\`.
- `РегистрСведений.СоставыНаборовLego` — `InformationRegisters\СоставыНаборовLego\`.

### Монеты / банкноты

- `РегистрСведений.ИнтернетСсылкиНоменклатуры` — `InformationRegisters\ИнтернетСсылкиНоменклатуры\` (измерения `Номенклатура` + `ИнтернетРесурс`; ресурс `ИнтернетСсылка`).
- `Справочник.ИнтернетРесурсы` — `Catalogs\ИнтернетРесурсы\` (тип измерения `ИнтернетРесурс`).
- `Константа.ИнтернетРесурс_МинифигуркиLego` / `_Монеты` / `_Банкноты` (значения ресурсов в данных).
- `ОбщийМодуль.ПарсингВызовСервера` — `CommonModules\ПарсингВызовСервера\` (диспетчер `ДополнитьРезультатПарсинга_<Источник>`).
- `ОбщийМодуль.ПолучениеДанныхСервер` / `ПолучениеДанныхКлиент` — `СкрыватьФото`, `ИнтернетРесурсДлаЗагрузкиЦен_*`.
- `ОбщийМодуль.РегулярныеВыраженияСервер` — `Test`, `Execute_Значение`.

### Фото-механизм (изображения/Аверс/Реверс)

Хранилище — подчинённый `Справочник.Изображения` (`Catalogs/Изображения/`,
`Ext/ManagerModule.bsl` — `СохранитьИзображение`, `ПолучитьРасширениеФайла`).
Типы — `Перечисление.ТипыИзображений` (`Enums/ТипыИзображений.xml`): `Фото1` (Аверс), `Фото2` (Реверс).

Общие модули:
- `ОбщийМодуль.СобытияФормКлиент` — `CommonModules/СобытияФормКлиент/Ext/Module.bsl` (513 строк):
  `ОбновитьФорму`, `ДобавитьИзображениеНаКлиенте`-делегаты, `ДобавитьИнформациюОПолученномИзображенииНаФорму`,
  `ПодготовитьИнформациюОбУдаляемомИзображенииНаФорме`, `ПоменятьМестамиИзображения`, `ПосмотретьФайл`,
  `ФильтрФайловИзображений`, `ПрогрессОбратныйВызов`, `ПолучитьСсылкиНаИзображения`, `ПолучитьОписаниеИзображения`.
- `ОбщийМодуль.СобытияФормСервер` — `CommonModules/СобытияФормСервер/Ext/Module.bsl` (814 строк):
  `ПолучитьСсылкиНаИзображения` (UNION ALL с приоритетом НЕ ПометкаУдаления), `СохранитьИзображениеИзВременногоХранилища`,
  `СохранитьИзображение` (делегат в менеджер `Изображения`), `ПолучитьРасширениеФайла` (делегат),
  `СохранитьИнформациюОбИзображенияхПослеЗаписи` (оркестратор записи фото), `ПолучитьОписаниеИзображения`.
- `ОбщийМодуль.ПолучениеДанныхСервер`/`Клиент` — `СкрыватьФото()` (прокси к `Константа.СкрыватьФото`).
- `ОбщийМодуль.ПарсингКлиент` — `CommonModules/ПарсингКлиент/Ext/Module.bsl` (получение фото из сети,
  оповещение формы-владельца через `ОбработатьПолучениеФайла`).
- `ОбщийМодуль.ПечатьДокументов` — `CommonModules/ПечатьДокументов/Ext/Module.bsl` (потребитель:
  запрос с `Изображения.ТипИзображения = ЗНАЧЕНИЕ(Перечисление.ТипыИзображений.ФотоN)`).

Формы с полным механизмом сохранения (добавить/удалить/`ФотоN_ТребуетсяОбновить`):
- `Catalogs/КлассификаторБанкнот/Forms/ФормаЭлемента` — 2 фото, есть `ПоменятьМестамиИзображения`.
- `Catalogs/КлассификаторМонет/Forms/ФормаЭлемента` — 2 фото, есть обмен.
- `Catalogs/КлассификаторМинифигурокLego/Forms/ФормаЭлемента` — 1 фото (только Фото1), обмена нет.
- `Catalogs/НаборыLego/Forms/ФормаЭлемента` — 2 фото, есть обмен.

Формы с просмотром (через `СоответствиеФото.Получить(...)` + `ПолучитьНавигационнуюСсылку`):
- `Catalogs/ПредметыКоллекции/Forms/ФормаЭлемента`, `Forms/ФормаЖурнала`.
- `Catalogs/Номенклатура/Forms/ФормаЭлемента` (только для вида `НаборыLego`).
- `Catalogs/{КлассификаторМонет,КлассификаторБанкнот,КлассификаторМинифигурокLego,НаборыLego}/Forms/ФормаСписка`.
- `DataProcessors/УправлениеКоллекцией/Forms/Форма`.
- `DataProcessors/ПодборНоменклатуры/Forms/ФормаПодбораПредметовКоллекции` (и 4 родственных —
  с закомментированным фото-кодом).
- Все формы документов (`Documents/*/Forms/ФормаДокумента`).

Парсеры с фото-механизмом:
- `DataProcessors/ПарсингСайтаUcoin/Forms/Форма`, `ПарсингСайтаCbr/Forms/Форма`,
  `ПарсингСайтаBricksapp/Forms/Форма`, `ПарсингСайтаBricklink/Forms/Форма` (нерабочая).

Требование аналитика: `.kilo/context/projects/collector/requirements/анализ.фото-механизмы__рефакторинг.md`.
