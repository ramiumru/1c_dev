# Справочник.Изображения

Проект:
`collector`

Путь:
`projects\collector\src\Catalogs\Изображения/` (метаданные: `Catalogs/Изображения.xml`;
менеджер: `Ext/ManagerModule.bsl`; форма: `Forms/ФормаЭлемента/Ext/Form/Module.bsl` — 9 строк, только `ПриСозданииНаСервере`).

Назначение:
Подчинённый справочник-хранилище двоичных данных изображений (Аверс/Реверс) для
владельцев: `КлассификаторБанкнот`, `КлассификаторМонет`, `КлассификаторМинифигурокLego`,
`НаборыLego`, `Номенклатура`. Один элемент = одно фото одного типа для одного владельца.
НЕ использует БСП-файловый модуль (`Файлы`/`СведенияОФайлах`/`ТомаХраненияФайлов`) —
двоичные данные хранятся в реквизите `Файл` типа `ХранилищеЗначения`.

Реквизиты (Use=ForItem):
- `Файл` (v8:ValueStorage) — двоичные данные изображения.
- `ТипИзображения` (EnumRef.ТипыИзображений) — Фото1 (Аверс) / Фото2 (Реверс).
- `Размер` (xs:decimal 10.0, Index) — размер в байтах.
- `ИмяБезРасширения` (Строка 200), `Расширение` (Строка 10), `Описание` (Строка неограниченная).

Что смотреть:
- `Ext/ManagerModule.bsl` — `СохранитьИзображение(СтруктураПараметров)` (поиск существующей
  записи по Владелец+ТипИзображения+НЕ ПометкаУдаления, перезапись файла без пометки
  старого), `ПолучитьРасширениеФайла(Ссылка, ТипИзображения)` (запрос).

Связанные объекты:
- `Перечисление.ТипыИзображений` (`Enums/ТипыИзображений.xml`) — Фото1, Фото2.
- `ОбщийМодуль.СобытияФормКлиент` (`CommonModules/СобытияФормКлиент/Ext/Module.bsl`).
- `ОбщийМодуль.СобытияФормСервер` (`CommonModules/СобытияФормСервер/Ext/Module.bsl`).
- `ОбщийМодуль.ПолучениеДанныхСервер`/`Клиент` (функция `СкрыватьФото`).
- Формы с фото-механизмом сохранения: `Catalogs/{КлассификаторБанкнот,КлассификаторМонет,КлассификаторМинифигурокLego,НаборыLego}/Forms/ФормаЭлемента`.

# Обработка.УдалениеПомеченныхОбъектов (БСП)

Проект:
`collector`

Путь:
`projects\collector\src\DataProcessors\УдалениеПомеченныхОбъектов.xml` (формы: `DataProcessors\УдалениеПомеченныхОбъектов\Forms\{ОсновнаяФорма,НастройкиУдаленияОбъектов,ВыборОбъектовМетаданныхПоПодсистемам}`)

Назначение:
Стандартная обработка БСП «Удаление помеченных объектов». Поиск и удаление объектов,
предварительно помеченных на удаление. Размещается в разделе «Администрирование».

Что смотреть:
- `DataProcessors\УдалениеПомеченныхОбъектов.xml` — метаданные обработки, команда `УдалениеПомеченныхОбъектов` (Group=NavigationPanelOrdinary), `UseStandardCommands=true`, форма `ОсновнаяФорма`.
- `Subsystems\Администрирование\Ext\CommandInterface.xml` — размещение команды в разделе: `Visibility/Common=true`, группа `NavigationPanelSeeAlso` (См. также).
- `FunctionalOptions\ИспользоватьУдалениеПомеченныхОбъектов.xml` — ФО с `Location=Constant.ИспользоватьУдалениеПомеченныхОбъектов`, `Content` включает `DataProcessor.УдалениеПомеченныхОбъектов` целиком.
- `CommonModules\УдалениеПомеченныхОбъектовСлужебный\Ext\Module.bsl` — `ПриДобавленииОбработчиковОбновления` (версия 2.4.1.1, `НачальноеЗаполнение=Истина`) вызывает `ВключитьУдалениеПомеченныхОбъектов`, который устанавливает константу в Истина; `ПриОпределенииНастроекРегламентныхЗаданий` — `ВключатьПриВключенииФункциональнойОпции=Ложь` (РЗ не включается автоматически с ФО).

Связанные объекты:
- `FunctionalOption.ИспользоватьУдалениеПомеченныхОбъектов` — `projects\collector\src\FunctionalOptions\ИспользоватьУдалениеПомеченныхОбъектов.xml`
- `Constant.ИспользоватьУдалениеПомеченныхОбъектов` (Boolean) — `projects\collector\src\Constants\ИспользоватьУдалениеПомеченныхОбъектов.xml`
- `Subsystem.СтандартныеПодсистемы.Subsystems.УдалениеПомеченныхОбъектов` (IncludeInCommandInterface=false, контейнер БСП) — `projects\collector\src\Subsystems\СтандартныеПодсистемы\Subsystems\УдалениеПомеченныхОбъектов.xml`
- `Subsystem.Администрирование` (IncludeInCommandInterface=true; Content содержит `DataProcessor.УдалениеПомеченныхОбъектов`) — `projects\collector\src\Subsystems\Администрирование.xml`
- `CommonModule.УдалениеПомеченныхОбъектовСлужебный` — `projects\collector\src\CommonModules\УдалениеПомеченныхОбъектовСлужебный\Ext\Module.bsl`
- `ScheduledJob.УдалениеПомеченныхОбъектов`, `ScheduledJob.КонтрольУдаленияПомеченныхОбъектов` — `projects\collector\src\ScheduledJobs\`

Ключевой вывод по видимости:
Обработка скрыта из интерфейса при `Константа.ИспользоватьУдалениеПомеченныхОбъектов = Ложь` (ФО целиком отключает объект через `Content`). Правка XML не нужна — нужно установить константу в Истина (через Панель администрирования БСП → Обслуживание, либо программно).

- `ОбщийМодуль.ПарсингВызовСервера` (диспетчер `_Bricksapp`→`ДополнитьРезультатПарсинга`)
- `Документ.УстановкаЦенНоменклатуры` (потребитель `ПолучитьЦены`/`ПолучитьЦеныВФоне`)

# РегистрСведений.ИнтернетСсылкиНоменклатуры

Проект:
`collector`

Путь:
`projects\collector\src\InformationRegisters\ИнтернетСсылкиНоменклатуры\` (метаданные: `InformationRegisters\ИнтернетСсылкиНоменклатуры.xml`; менеджер: `Ext\ManagerModule.bsl`)

Назначение:
Хранение интернет-ссылок на номенклатуру (минифигурки/наборы Lego, банкноты, разновидности монет) с отбором по `ИнтернетРесурс`.

Что смотреть:
- `InformationRegisters\ИнтернетСсылкиНоменклатуры.xml` — непериодический, независимый; ресурс `ИнтернетСсылка` (Строка); измерение `Номенклатура` (составной: `КлассификаторБанкнот`/`КлассификаторМинифигурокLego`/`РазновидностиМонет`/`НаборыLego`, Master); измерение `ИнтернетРесурс` (`СправочникСсылка.ИнтернетРесурсы`).
- `Ext\ManagerModule.bsl` — `ПолучитьСсылку(Номенклатура, ИнтернетРесурс)`, `ПолучитьМассивСсылокНоменклатуры`, `ДобавитьЗаписьИнтернетСсылка`, `ЗаписатьИнтернетСсылкиДляМонеты`.

Связанные объекты:
- `Справочник.ИнтернетРесурсы` (тип измерения `ИнтернетРесурс`)
- `Константа.ИнтернетРесурс_МинифигуркиLego` (значение `ИнтернетРесурс` для Lego-минифигурок; возвращается `ПолучениеДанныхСервер.ИнтернетРесурсДлаЗагрузкиЦен_МинифигуркиLego()`)
- `ОбщийМодуль.ПолучениеДанныхСервер` / `ПолучениеДанныхКлиент` (`СкрыватьФото`, `ПолучитьИнтернетСсылку`)
