# /form-data-types — справочник по типам ДанныеФормы*

Справочник по платформенным типам `ДанныеФормы*`, которые представляют данные реквизитов управляемой формы на сервере. Вызывай **перед** написанием кода, работающего с реквизитами формы типа «ДеревоЗначений», «ТаблицаЗначений», «СписокЗначений», чтобы не допустить типовых ошибок вызова несуществующих методов.

**Как использовать:** найди нужный тип, сверь список доступных методов, проверь себя по сводной таблице и разделу частых ошибок.

> **Источник данных:** методы и свойства типов сверены с Синтакс-Помощником 1С через MCP `onec-platform-help`. Тип `ДанныеФормыСписок` в Синтакс-Помощнике не обнаружен — см. примечание в соответствующем разделе.

---

## Почему это важно

Реквизит формы типа «ДеревоЗначений» на сервере имеет тип `ДанныеФормыДерево`, а **не** `ДеревоЗначений`. У `ДанныеФормыДерево` **нет** методов `Очистить()`, `Добавить()`, `Количество()` — они есть у коллекции элементов, которую возвращает `ПолучитьЭлементы()`. Аналогично для таблиц — тип `ДанныеФормыКоллекция`, для структур — `ДанныеФормыСтруктура`.

Типичная ошибка:

```bsl
// НЕВЕРНО — у ДанныеФормыДерево нет метода Очистить()
ДеревоМетаданных.Очистить();

// ВЕРНО — очищаем коллекцию элементов верхнего уровня
ДеревоМетаданных.ПолучитьЭлементы().Очистить();
```

## 1. Тип `ДанныеФормыДерево` (Form Data Tree)

**Описание:** представляет дерево значений в управляемой форме. Реквизит формы типа «ДеревоЗначений» на сервере имеет тип `ДанныеФормыДерево`.

**Методы** (по данным Синтакс-Помощника):

| Метод | Описание |
|-------|----------|
| `ПолучитьЭлементы()` | Возвращает `ДанныеФормыКоллекцияЭлементовДерева` — коллекцию строк верхнего уровня |
| `НайтиПоИдентификатору(Идентификатор)` | Ищет строку дерева по идентификатору, возвращает `ДанныеФормыЭлементДерева` или `Неопределено` |

**Важно:** у `ДанныеФормыДерево` **НЕТ** методов `Очистить()`, `Добавить()`, `Количество()`, `Найти()`, `Удалить()`. Все операции со строками выполняются через `ПолучитьЭлементы()`.

**Свойства колонок** доступны через точку у элемента дерева: `СтрокаДерева.ИмяКолонки`.

**Как очистить:**

```bsl
Дерево.ПолучитьЭлементы().Очистить();
```

**Как добавить строку верхнего уровня:**

```bsl
СтрокаДерева = Дерево.ПолучитьЭлементы().Добавить();
```

**Как получить дочерние строки:**

```bsl
ДочерниеСтроки = СтрокаДерева.ПолучитьЭлементы();
```

## 2. Тип `ДанныеФормыКоллекцияЭлементовДерева` (Form Data Tree Element Collection)

**Описание:** коллекция строк дерева (дочерних элементов). Возвращается методом `ПолучитьЭлементы()` как у `ДанныеФормыДерево`, так и у `ДанныеФормыЭлементДерева`.

**Методы** (по данным Синтакс-Помощника):

| Метод | Описание |
|-------|----------|
| `Добавить()` | Добавляет новую строку, возвращает `ДанныеФормыЭлементДерева` |
| `Очистить()` | Удаляет все строки коллекции |
| `Количество()` | Возвращает количество строк в коллекции |
| `Удалить(Элемент)` | Удаляет указанную строку |
| `Вставить(Индекс)` | Вставляет новую строку по индексу |
| `Получить(Индекс)` | Получает строку по индексу |
| `Индекс(Элемент)` | Возвращает индекс строки в коллекции |
| `Сдвинуть(Элемент, Смещение)` | Сдвигает строку на указанное количество позиций |

**Важно:** у `ДанныеФормыКоллекцияЭлементовДерева` **НЕТ** метода `Найти()` (в отличие от `ДеревоЗначений`). Для поиска используйте перебор или `НайтиПоИдентификатору()` у родительского `ДанныеФормыДерево`.

**Пример — перебор строк верхнего уровня:**

```bsl
Для Каждого СтрокаДерева Из Дерево.ПолучитьЭлементы() Цикл
    Сообщить(СтрокаДерева.ИмяКолонки);
КонецЦикла;
```

## 3. Тип `ДанныеФормыЭлементДерева` (Form Data Tree Element)

**Описание:** отдельная строка дерева. Возвращается методом `Добавить()` или `Получить(Индекс)` у коллекции элементов дерева.

**Методы** (по данным Синтакс-Помощника):

| Метод | Описание |
|-------|----------|
| `ПолучитьЭлементы()` | Возвращает `ДанныеФормыКоллекцияЭлементовДерева` — дочерние строки |
| `ПолучитьРодителя()` | Возвращает родительский элемент дерева или `Неопределено` |
| `ПолучитьИдентификатор()` | Возвращает идентификатор строки (для `НайтиПоИдентификатору`) |
| `Свойство(Ключ, Значение)` | Проверяет наличие свойства (колонки) и получает его значение |

**Свойства:** значения колонок доступны через точку — `СтрокаДерева.ИмяКолонки`.

**Важно:** у `ДанныеФормыЭлементДерева` **НЕТ** методов `Очистить()`, `Добавить()`, `Количество()`. Для операций с дочерними строками используй `ПолучитьЭлементы()`.

**Как добавить дочернюю строку:**

```bsl
ДочерняяСтрока = СтрокаДерева.ПолучитьЭлементы().Добавить();
```

## 4. Тип `ДанныеФормыКоллекция` (Form Data Collection)

**Описание:** представляет таблицу значений в управляемой форме. Реквизит формы типа «ТаблицаЗначений» на сервере имеет тип `ДанныеФормыКоллекция`.

**Методы** (по данным Синтакс-Помощника):

| Метод | Описание |
|-------|----------|
| `Добавить()` | Добавляет новую строку |
| `Очистить()` | Удаляет все строки |
| `Количество()` | Возвращает количество строк |
| `Удалить(Элемент)` | Удаление строки |
| `Вставить(Индекс)` | Вставка строки по индексу |
| `Получить(Индекс)` | Получение строки по индексу |
| `Индекс(Элемент)` | Возвращает индекс строки |
| `НайтиСтроки(ПараметрыОтбора)` | Поиск строк по параметрам отбора, возвращает массив |
| `НайтиПоИдентификатору(Идентификатор)` | Поиск строки по идентификатору |
| `Сдвинуть(Элемент, Смещение)` | Сдвиг строки |
| `Сортировать(Колонки, Направление)` | Сортировка строк по колонкам |
| `Итог(Колонка)` | Возвращает итог по колонке (сумма и т.п.) |
| `Выгрузить(Колонки)` | Выгружает данные в таблицу значений |
| `Загрузить(Таблица)` | Загружает данные из таблицы значений |

**Важно:** у `ДанныеФормыКоллекция` **НЕТ** метода `Найти(Значение, Колонки)` (как у `ТаблицаЗначений`). Используйте `НайтиСтроки()` для поиска по отбору.

**Пример — заполнение таблицы:**

```bsl
Таблица.Очистить();
Для Сч = 1 По 10 Цикл
    СтрокаТаблицы = Таблица.Добавить();
    СтрокаТаблицы.Имя = "Элемент " + Сч;
    СтрокаТаблицы.Значение = Сч * 2;
КонецЦикла;
```

**Пример — поиск строк:**

```bsl
ПараметрыОтбора = Новый Структура("Имя", "Элемент 5");
НайденныеСтроки = Таблица.НайтиСтроки(ПараметрыОтбора);
Для Каждого НайденнаяСтрока Из НайденныеСтроки Цикл
    Сообщить(НайденнаяСтрока.Значение);
КонецЦикла;
```

## 5. Тип `ДанныеФормыСтруктура` (Form Data Structure)

**Описание:** представляет структуру в управляемой форме. Реквизит формы типа «Структура» на сервере имеет тип `ДанныеФормыСтруктура`.

**Методы** (по данным Синтакс-Помощника):

| Метод | Описание |
|-------|----------|
| `Свойство(Ключ, Значение)` | Проверяет наличие свойства и получает его значение |

**Свойства:**

| Свойство | Описание |
|----------|----------|
| `<Имя свойства>` | Значения свойств доступны через точку — `СтруктураФормы.ИмяСвойства` |
| `ИсходныйКлючЗаписи` | Системное свойство |

**Важно:** у `ДанныеФормыСтруктура` **НЕТ** методов `Вставить()`, `Удалить()`, `Количество()` (в отличие от `Структура`). Добавление и удаление свойств выполняется через редактирование реквизитов формы в конфигураторе, а не из кода.

**Пример:**

```bsl
ЗначениеСвойства = Неопределено;
Если СтруктураФормы.Свойство("Имя", ЗначениеСвойства) Тогда
    Сообщить(ЗначениеСвойства);
КонецЕсли;

// Доступ через точку
Значение = СтруктураФормы.Имя;
```

## 6. Тип `ДанныеФормыСписок` (Form Data List)

> ⚠️ **Примечание:** тип `ДанныеФормыСписок` **не обнаружен** в Синтакс-Помощнике 1С через MCP `onec-platform-help`. Информация ниже основана на общих сведениях о работе со списками значений в формах и требует проверки в конкретной версии платформы. Для работы со списком значений на сервере формы также может использоваться тип `СписокЗначений` (методы: `Добавить`, `Очистить`, `Количество`, `Удалить`, `НайтиПоЗначению`, `НайтиПоИдентификатору` и др.).

**Описание:** представляет список значений в управляемой форме. Реквизит формы типа «СписокЗначений» на сервере может иметь тип `ДанныеФормыСписок`.

**Ожидаемые методы** (требуют проверки):

| Метод | Описание |
|-------|----------|
| `Добавить(Значение, Представление, Пометка, Картинка)` | Добавляет элемент списка |
| `Очистить()` | Удаляет все элементы |
| `Количество()` | Возвращает количество элементов |
| `Удалить(Элемент)` | Удаляет указанный элемент |
| `НайтиПоЗначению(Значение)` | Поиск элемента по значению |

**Пример:**

```bsl
Список.Очистить();
Список.Добавить(1, "Первый");
Список.Добавить(2, "Второй");
ЭлементСписка = Список.НайтиПоЗначению(1);
```

## 7. Сводная таблица: что можно и нельзя делать с типами ДанныеФормы*

| Тип | `Очистить()` | `Добавить()` | `ПолучитьЭлементы()` | `Количество()` |
|-----|:------------:|:------------:|:-------------------:|:---------------:|
| `ДанныеФормыДерево` | ❌ НЕТ | ❌ НЕТ | ✅ Да | ❌ НЕТ |
| `ДанныеФормыКоллекцияЭлементовДерева` | ✅ Да | ✅ Да | ❌ НЕТ | ✅ Да |
| `ДанныеФормыЭлементДерева` | ❌ НЕТ | ❌ НЕТ | ✅ Да | ❌ НЕТ |
| `ДанныеФормыКоллекция` | ✅ Да | ✅ Да | ❌ НЕТ | ✅ Да |
| `ДанныеФормыСтруктура` | ❌ НЕТ | ❌ НЕТ | ❌ НЕТ | ❌ НЕТ |
| `ДанныеФормыСписок` ⚠️ | ✅ Да* | ✅ Да* | ❌ НЕТ | ✅ Да* |

> \* Данные по `ДанныеФормыСписок` не подтверждены Синтакс-Помощником — см. примечание в разделе 6.

**Ключевое правило:** если у типа **нет** нужного метода — ищи метод, который вернёт коллекцию (обычно `ПолучитьЭлементы()`), и вызывай метод у неё.

## 8. Частые ошибки и их решения

| ❌ Ошибка | ✅ Правильно | Причина |
|-----------|-------------|---------|
| `ДеревоМетаданных.Очистить()` | `ДеревоМетаданных.ПолучитьЭлементы().Очистить()` | У `ДанныеФормыДерево` нет `Очистить()` |
| `ДеревоМетаданных.Добавить()` | `ДеревоМетаданных.ПолучитьЭлементы().Добавить()` | У `ДанныеФормыДерево` нет `Добавить()` |
| `ДеревоМетаданных.Количество()` | `ДеревоМетаданных.ПолучитьЭлементы().Количество()` | У `ДанныеФормыДерево` нет `Количество()` |
| `СтрокаДерева.Очистить()` | `СтрокаДерева.ПолучитьЭлементы().Очистить()` | У `ДанныеФормыЭлементДерева` нет `Очистить()` |
| `СтрокаДерева.Добавить()` | `СтрокаДерева.ПолучитьЭлементы().Добавить()` | У `ДанныеФормыЭлементДерева` нет `Добавить()` |
| `Дерево.Найти(Значение, Колонки)` | Перебор `ПолучитьЭлементы()` или `Дерево.НайтиПоИдентификатору()` | У `ДанныеФормыДерево` нет `Найти()` |
| `Таблица.Найти(Значение, Колонки)` | `Таблица.НайтиСтроки(ПараметрыОтбора)` | У `ДанныеФормыКоллекция` нет `Найти()` |
| `СтрокаДерева.ПолучитьЭлементы().Найти(...)` | Перебор коллекции вручную | У `ДанныеФормыКоллекцияЭлементовДерева` нет `Найти()` |

## 9. Примеры кода

### 9.1. Заполнение дерева с дочерними строками

```bsl
// Очистка дерева
ДеревоМетаданных.ПолучитьЭлементы().Очистить();

// Добавление строки верхнего уровня
СтрокаВерхнегоУровня = ДеревоМетаданных.ПолучитьЭлементы().Добавить();
СтрокаВерхнегоУровня.Имя = "Справочники";
СтрокаВерхнегоУровня.Количество = 5;

// Добавление дочерней строки
ДочерняяСтрока = СтрокаВерхнегоУровня.ПолучитьЭлементы().Добавить();
ДочерняяСтрока.Имя = "Контрагенты";
ДочерняяСтрока.Количество = 1;
```

### 9.2. Очистка дерева

```bsl
// Очистить все строки верхнего уровня (дочерние удалятся автоматически)
ДеревоМетаданных.ПолучитьЭлементы().Очистить();
```

### 9.3. Перебор дерева с обходом дочерних строк

```bsl
Процедура ВывестиДерево(КоллекцияСтрок, Уровень = 0)

    Для Каждого СтрокаДерева Из КоллекцияСтрок Цикл
        Отступ = "";
        Для Сч = 1 По Уровень Цикл
            Отступ = Отступ + "  ";
        КонецЦикла;
        Сообщить(Отступ + СтрокаДерева.Имя);

        // Рекурсивный обход дочерних строк
        ВывестиДерево(СтрокаДерева.ПолучитьЭлементы(), Уровень + 1);
    КонецЦикла;

КонецПроцедуры;

ВывестиДерево(ДеревоМетаданных.ПолучитьЭлементы());
```

### 9.4. Поиск строки по идентификатору

```bsl
// Идентификатор можно получить заранее: СтрокаДерева.ПолучитьИдентификатор()
НайденнаяСтрока = ДеревоМетаданных.НайтиПоИдентификатору(Идентификатор);
Если НайденнаяСтрока <> Неопределено Тогда
    Сообщить(НайденнаяСтрока.Имя);
КонецЕсли;
```

### 9.5. Удаление строки из дерева

```bsl
// Удаление первой строки верхнего уровня
КоллекцияСтрок = ДеревоМетаданных.ПолучитьЭлементы();
Если КоллекцияСтрок.Количество() > 0 Тогда
    СтрокаДляУдаления = КоллекцияСтрок.Получить(0);
    КоллекцияСтрок.Удалить(СтрокаДляУдаления);
КонецЕсли;
```

### 9.6. Работа с таблицей (ДанныеФормыКоллекция)

```bsl
// Очистка
ТаблицаРезультатов.Очистить();

// Добавление и заполнение строк
Для Сч = 1 По 10 Цикл
    НоваяСтрока = ТаблицаРезультатов.Добавить();
    НоваяСтрока.Номер = Сч;
    НоваяСтрока.Сумма = Сч * 100;
КонецЦикла;

// Поиск строк по отбору
ПараметрыОтбора = Новый Структура("Номер", 5);
НайденныеСтроки = ТаблицаРезультатов.НайтиСтроки(ПараметрыОтбора);

// Получение итога по колонке
СуммаИтог = ТаблицаРезультатов.Итог("Сумма");
```

### 9.7. Преобразование ДанныеФормы* в прикладные типы и обратно

```bsl
// Дерево формы → ДеревоЗначений
ДеревоЗначений = ДанныеФормыВЗначение(ДеревоМетаданных, Тип("ДеревоЗначений"));

// Таблица формы → ТаблицаЗначений
ТаблицаЗначений = ДанныеФормыВЗначение(ТаблицаРезультатов, Тип("ТаблицаЗначений"));

// Обратно: ДеревоЗначений → Дерево формы
ЗначениеВДанныеФормы(ДеревоЗначений, ДеревоМетаданных);
```

## 10. Связанные типы

| Тип | Описание |
|-----|----------|
| `ДанныеФормыСтруктураСКоллекцией` | Структура с вложенной коллекцией (таблицей). Методы объединяют `Свойство` и коллекционные: `Добавить`, `Очистить`, `Количество`, `НайтиСтроки`, `Сортировать` и др. |
| `ДанныеФормыЭлементСписка` | Элемент списка значений формы. Свойства: `Значение`, `Представление`, `Пометка`, `Картинка`. |
